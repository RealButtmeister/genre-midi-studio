# Embedded dependency notice

`genre_midi/vendor/motion_fx_codec.py` is the existing locally bundled Motion FX MIDI protocol codec from Genre MIDI Studio. Its source header and implementation are preserved. Genre MIDI Studio imports its target definitions and score validation to generate compatible automation.

No standalone Motion FX application or plugin files are included. No separate license notice accompanied the codec in the source distribution; this notice records provenance and does not grant a new license. The standalone plugin's build system and dependencies are not needed to run Genre MIDI Studio.
